Реальная проверка Steam обнаружила две ошибки первоначального инструмента:
выбиралась reference DLL вместо Windows runtime DLL, а служебные строки SDK
мешали разбору JSON. Исправлены путь/хеш и однозначный tagged-result протокол.
Повторная проверка на изменённом коде прошла. SDK account diagnostics лаунчер
не выводит и не сохраняет.

Репозиторий и выпуск инструментов не считаются готовой установкой полного набора.
Стабильный игровой канал останется `pending` до необходимых проверок.
