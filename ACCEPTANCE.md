Проверка низкой памяти подтвердила отказ до чтения мира при недостаточном commit.
Исходный мир и тестовая копия сохранили хеши. Этот отказ сам по себе не доказывает
повреждение мира. В версии 0.29.3 добавлено соответствующее сообщение для
одиночного клиентского экрана. Сервер и подключающийся клиент при нехватке памяти
ещё могут показать штатную ошибку загрузки/синхронизации; защита серверного
восстановления из резервной копии подготовлена отдельно и в этот релиз не входит.

Предыдущие неудачные диагностические попытки сохранены в локальных журналах.
Они выявили конфликт старого запрета стартовых подарков и два неверных момента
выполнения теста относительно готовности рецептов. Исправления прошли повторные
целевые проверки. Существовавшие до запуска клиента файлы проверки сохранности
были отдельно подтверждены по содержимому; игровой клиент не создавал сохранений.

Для старого GitHub updater v5 публикуется совместимая миграция инструментов.
Для полного preset после неё запускается новый Install-DingDong.cmd.
Личный FTP R33 проверен отдельно: 94 проверки новых функций, 7 проверок UI,
20 проверок стартового набора/разборки, каталог 9 652 типов и обновление с
13 базовых версий. Исправления Luiafk и пакетов androLib проверены нативными
вызовами; это не приёмка настоящей сети с двумя клиентами.

Серия 36 000 обновлений пугала сохраняет цель и опыт. Настоящий бой миньонов
этой проверкой не моделировался; причина сообщённого отказа цели остаётся
неподтверждённой. Для следующего случая добавлен журнал переходов состояния.
