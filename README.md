# DingDong

Русскоязычная сборка Terraria/tModLoader и инструменты её установки и обновления.

## Статус публикации

Репозиторий ведётся отдельно от личной установленной сборки **R22 / 0.28.8**.
Полная сборка R22 здесь не распространяется: её архив содержит файлы игры,
сторонние моды и схемы построек, для которых не подтверждены права на публичное
распространение. Наличие покупки Terraria не заменяет разрешение правообладателей
на размещение этих файлов.

Пока проверка публичного состава не завершена, обновлятор должен сообщать об
отсутствии опубликованной игровой версии и не изменять установленную игру.
Успешная проверка инструментов не означает готовность публичной игровой сборки.

По решению владельца готовится отдельный публичный кандидат **0.29.0**: собственные
планы домов и оригинальные изображения заменяют материалы с неподтверждёнными
правами. Готовый публичный кандидат, результаты проверки и ограничения будут
помечены отдельно от стабильного игрового релиза.

## Как должна устанавливаться публичная версия

1. Игрок устанавливает лицензионную Terraria и официальный tModLoader через Steam.
2. Установщик проверяет официальную установку и право доступа к Terraria в Steam.
3. Из GitHub Releases загружаются только проверенные разрешённые файлы DingDong.
4. Чужие компоненты получаются из официальных источников по их условиям; проверяются
   требуемые версии и SHA-256. Отсутствующий или несовместимый компонент останавливает
   установку с понятным сообщением.
5. Изменения движка применяются локально к проверенной официальной основе.
6. Перед заменой управляемых файлов создаётся резервная копия. Папки миров и
   персонажей не входят в состав обновления.

Текущий репозиторий не предоставляет подтверждения, что все эти этапы уже проверены
на новом компьютере. Точный результат приёмки будет указан в релизе.

## Обновлятор

Исходники находятся в `updater/`. Новый канал использует GitHub Releases,
подписанный манифест и проверку содержимого. Старые FTP-пакеты не являются
разрешёнными публичными обновлениями этого репозитория.

Выпуск инструментов `v0.1.0-bootstrap` содержит обновлятор и подписанное сообщение
об отсутствии готового игрового релиза. Это не обновление игры R23.

Перед установкой нужно штатно закрыть tModLoader и его сервер. Обновлятор не
должен принудительно завершать игру и не должен обновлять сохранения.
