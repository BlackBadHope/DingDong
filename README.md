# DingDong Public

Отдельная сборка Terraria/tModLoader с DingDong: Biome Homes, большим миром,
61 резиденцией NPC, квестами, снаряжением и совместимостью модов.

## Установка и обновление

1. Установите **Terraria** и **tModLoader 2026.8.3.0** через Steam. Войдите в Steam
   и оставьте его запущенным в онлайн-режиме.
2. Скачайте `DingDong-GitHub-Installer-v1.zip` из
   [последнего релиза](https://github.com/BlackBadHope/DingDong/releases/latest).
3. Распакуйте установщик в отдельную папку и запустите `Install-DingDong.cmd`.
4. После установки запускайте `Launch-DingDong.cmd` в `%LOCALAPPDATA%\DingDong-GitHub`.

Можно также скачать исходники репозитория и запустить корневой
`Install-DingDong.cmd`. **.NET SDK, Git и права администратора игроку не нужны.**
Поддерживается Windows x64. Кеш хранится в `Downloads` рядом с установщиком.

Для **обновления или ремонта** снова запустите установщик. Он получает последний
опубликованный релиз GitHub, проверяет RSA-подпись, SHA-256 архива и каждого файла.
Совпадения номера версии недостаточно: повреждённые управляемые файлы обнаруживаются.
Штатно закройте игру и сервер перед обновлением; установщик сам процессы не завершает.

```powershell
# Другой отдельный каталог:
.\Install-DingDong.ps1 -InstallPath 'D:\Games\DingDong'
# Только скачать и проверить собственный пакет:
.\Install-DingDong.ps1 -DownloadOnly
```

## Источники и состав

- **GitHub проекта:** собственный мод, инструменты и настройки по умолчанию.
  Подписанный `install.json` связывает тег, хеши файлов и исходный commit.
- **Локальный Steam:** ресурсы/runtime tModLoader копируются в отдельную папку.
  Патчер локально меняет один аргумент изоляции Workshop у Host & Play.
  Официальная Steam-установка не изменяется.
- **Steam Workshop:** 63 сторонних компонента. Точные ранее скачанные файлы
  используются повторно; недостающие запрашиваются через официальный Steam API.
- **Релиз автора:** StructureHelper 3.1.1 скачивается напрямую у автора.
- **Исходники автора:** OreExcavator 0.8.9 собирается локально из зафиксированного
  commit, с компилятором официального tModLoader. Дополнительный SDK не нужен.
  Хеши исходного архива и детерминированного результата обязательны.

В публичном preset **66 модов**, включая DingDong и официальный Project tRU.
Отдельный `PackWorldgenFix` исключён: его собственные защиты включены в DingDong.
Для OreExcavator используется Release-сборка 0.8.9 без устаревшей отладочной
библиотеки TUnit. Исходный игровой код автора сохраняется; готовый чужой мод
в GitHub-релиз не включается.
Точный состав: [bootstrap/public-dependencies.json](bootstrap/public-dependencies.json).

Если требуемый пакет больше недоступен у автора/в Steam, установка останавливается
до замены модов. Иная версия не подставляется молча. Список проблем сохраняется
в `Downloads/dependency-readback.json`; завершённые скачивания используются при повторе.

## Включённый быстрый фикс

Новый персонаж получает комплект Magic Storage ровно на **128 ячеек**: три
обычных блока, два маленьких, сердце, доступ к крафту, дополнительный доступ
и соединители. После смерти и при повторном входе комплект не выдаётся.
Разборщик предлагает один базовый рецепт исходного предмета; обмен предметами
из общей группы мебели отключён. При недостатке памяти одиночный клиент объясняет
отказ загрузки мира. На сервере и при подключении клиента ещё возможны штатное
сообщение об отсутствии резервной копии и ошибка синхронизации: нехватка памяти
сама по себе не означает повреждение мира.

## Исправление R34 / 0.29.4

Авторазборка и Auto Trash теперь имеют две настоящие ячейки в одном интерфейсе.
У каждой есть собственные выключатель и редактируемый список. Предмет переносится
с курсора в ячейку; очередь разборки сохраняется при выходе. Повторное помещение
предмета сохраняет его правило. Избранное защищено, полный инвентарь приостанавливает
разборку. Auto Trash сохраняет существующие правила и штатную обработку подбора,
продажи и возврата последнего предмета.

При отказе запуска сервера из-за памяти загрузка теперь останавливается до
попытки восстановить `.bak`: нехватка памяти не запускает замену файла мира.
Подробные границы проверки приведены в [ACCEPTANCE.md](ACCEPTANCE.md).
Обновите оба клиента и сервер, затем перезапустите их.

## Обновление R33

Авторазборка находится рядом с AutoTrash: отдельный слот, выключатель и список
правил. Она изначально выключена; предмет на курсоре задаёт правило, избранное
защищено, заполненный инвентарь приостанавливает обработку. Дублирующая корзина
ImproveGame отключена; остальные функции мода сохранены.

Подсказки предметов сокращены. Подробности Signature, Weapon Enchantments и
«Души вечности» перенесены в DingDong Menu. Рост количества снарядов и скидки
слотов миньонов сохранён; бонусы остальных характеристик Signature ограничены.
Открываемые ящики расходуются даже с включённым строительным эффектом Fargo.
Исправлены сетевой строительный курсор Luiafk и синхронизация хранилища androLib.

Основные стандартные клавиши: **F** — рывок, **Y** — способность брони,
**V/X** — ярость/адреналин, **Z** — перенос к курсору.
**F1** — DingDong Menu, **F2** — задания, **F3/F4** — журнал/список боссов,
**F5** — избранные рецепты, **F6** — строительство, **F7** — смена персонажа,
**F8** — управление ImproveGame. Комплекты снаряжения: **F9–F11**.
При первом применении настроек сохраняется резервная копия клавиш; собственные
назначения сохраняются. В последующих запусках раскладка не сбрасывается.

Проверка пугала сохранила доступность цели и опыт в ускоренной серии штатных
вызовов обновления. Сбой после длительного боя настоящих миньонов пока не
воспроизведён; журнал состояния добавлен для точной диагностики. См. [проверки](ACCEPTANCE.md).

Эксперимент `AutoNormalizeExpandedWorldGrowth` по умолчанию выключен.
Он может уменьшать нагрузку ценой более редкого роста растений на больших
мирах; живой замер его пользы ещё не выполнен.

## Сохранения и откат

Новая установка использует отдельный `Profile`. Steam/FTP миры, персонажи и карты
автоматически не переносятся и не изменяются. При обновлении внутри этой установки
заменяются управляемые моды; `Players`, `Worlds`, карты, клавиши и существующие
ModConfigs сохраняются. Новые настройки добавляются только при отсутствии файла.

Старые моды и указатель версии сохраняются в `Backups`; точный путь выводится
после обновления. При закрытой игре:

```powershell
.\Install-DingDong.ps1 -InstallPath 'D:\Games\DingDong' -RollbackBackup 'D:\Games\DingDong\Backups\<id>'
```

Незавершённая транзакция восстанавливается перед следующей установкой.
Ошибка подписи, хеша, списка ZIP или источника останавливает замену файлов.

## Старый обновлятор GitHub v5

Он получает совместимый подписанный пакет инструментов. После его выполнения
запустите `Bootstrap\Tools\Install-DingDong.cmd` рядом с обновлятором.
Будет создана отдельная публичная установка. FTP/R22–R33 остаются самостоятельным
каналом и не превращаются в публичную версию заменой одного `.tmod`.

## Права и проверка

В релизе нет Terraria, полной игровой DLL, зеркал сторонних `.tmod`, Project tRU,
сохранений или приватных схем. В моде 158 оригинальных изображений, 36 схем
Structify с MIT notice и собственные процедурные замены приватных домов.
