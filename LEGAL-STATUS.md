# Права на распространение

Дата проверки: 22 октября 2026 года.

Это запись о границах текущей публикации, а не заключение юриста и не разрешение
правообладателей на распространение чужих произведений.

| Компонент | Публичная публикация в этом репозитории |
| --- | --- |
| Новые собственные инструменты установки и обновления | Только после проверки исходников и состава |
| Купленная Terraria: исполняемые файлы, оригинальные ресурсы и полный декомпилированный код | Не включаются |
| Официальный tModLoader и его изменения | Только в пределах точной лицензии соответствующего файла; полная игровая DLL не включается автоматически |
| Сторонние `.tmod`, музыка и русификаторы | Не включаются без подтверждённого права на зеркалирование |
| Схемы из сторонних Workshop-миров с внутренней пометкой PRIVATE_ONLY | Не включаются; разрешение автора не получено |
| Пользовательские миры, персонажи, настройки аккаунтов и ключи подписи | Не включаются |

Проверка Steam-покупки предназначена для проверки доступа к игре. Она не делает
правомерным размещение чужих игровых файлов и не является неустранимой защитой
от изменения открытого кода запуска.

## Неразрешённый полный пакет

Полный личный пакет **R22 / 0.28.8** не прошёл допуск к публичному распространению.
Текущий файл `DingDongBiomeHomes.tmod` также нельзя автоматически считать
разрешённым: он упаковывает исходники и сторонние схемы построек.

Публичная игровая версия требует либо разрешений на соответствующие ресурсы,
либо отдельной версии с оригинальными заменами. Локальная проверка хеша и запуск
сервера не заменяют проверку прав на распространение.

В текущем нативном DingDong 0.28.8 подтверждены 90 файлов схем PrivateHome.
У 158 прочих графических и иных бинарных ресурсов не установлен достаточный
реестр происхождения. Эти материалы в данный репозиторий не экспортируются.

Project tRU имеет отдельный явный запрет зеркалирования и распространения вне
официальных ресурсов. Его `.tmod`, переводы, графика и аудио не публикуются здесь.
Официальная лицензия: [Project tRU LICENSE.md](https://github.com/RazzSG/ProjectTRU/blob/Main/LICENSE.md).

## Разделение лицензий

Для собственных файлов действует ограниченное разрешение на личное использование
[LICENSE-ORIGINAL.txt](LICENSE-ORIGINAL.txt). Общая свободная лицензия MIT/GPL
на весь проект не предоставляется. Публичная видимость репозитория сама по себе
не означает передачу прав на все его составляющие.
Сторонние лицензии применяются только к отмеченным соответствующим компонентам.

## Отдельный публичный кандидат

По решению владельца создаётся самостоятельная версия 0.29.0 с собственными
заменами спорных материалов. Все 90 приватных файлов исключены; 88 логических
вариантов построек получают оригинальные процедурные планы. Все 158 изображений
перерисованы оригинальным геометрическим генератором без чтения исходных пикселей.
36 схем Structify сохраняются по их MIT-лицензии вместе с полным notice.
Заимствованные внешние блоки локализации исключены; специальные шутки перевода
заменены самостоятельными новыми подсказками.

Положительная проверка исходников и состава пакета не подтверждает полноценную
чистую установку и игровой сценарий. Сторонние моды и Project tRU по-прежнему
не зеркалируются: пользователю нужны их официальные источники.
