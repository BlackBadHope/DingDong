# Границы публичного пакета

Дата: 23 октября 2026 года. Публикуется отдельная версия **DingDong Public 0.29.3**.
Личный FTP-пакет и публичная версия используют разные наборы ресурсов.

В GitHub входят собственные исходники и инструменты, собственный собранный мод,
158 оригинальных изображений и 36 схем Structify с
[уведомлением MIT](game-mod/DingDongBiomeHomes/ThirdPartyNotices/Structify-MIT.txt).
90 файлов PrivateHome исключены. Их 88 логических вариантов заменены собственными
процедурными планами. Исходные пиксели спорных изображений не использовались.
Заимствованные внешние блоки перевода в исходники публичного мода не включены.

На собственные файлы действует
[LICENSE-ORIGINAL.txt](LICENSE-ORIGINAL.txt), а не общая MIT/GPL-лицензия на сборку.
Для инструментальной зависимости Mono.Cecil 0.11.6 в выпуск включается её отдельная
лицензия MIT. Это разрешение не распространяется на сторонние игровые моды.

В репозитории и его release assets отсутствуют Terraria, её ресурсы, полная
патченая игровая DLL, сторонние `.tmod`, музыка, Project tRU, сохранения и ключи
подписи. Runtime копируется из официальной локальной установки Steam и изменяется
на компьютере игрока. Сторонние моды скачиваются из Steam Workshop и источников
авторов; OreExcavator собирается из точного архива автора на компьютере игрока.

Проверка Steam подтверждает доступ к Terraria для запуска. Она не предоставляет
прав на зеркалирование чужих материалов. Project tRU устанавливается из
официального Steam-источника; его файлы в релиз проекта не включаются.

Первичные лицензии:

- [tModLoader на используемом commit](https://github.com/tModLoader/tModLoader/blob/c9545cf27d56c456321e1896274c02adf67d0140/LICENSE)
- [Project tRU](https://github.com/RazzSG/ProjectTRU/blob/Main/LICENSE.md)
- [Mono.Cecil 0.11.6](https://github.com/jbevain/cecil/blob/0.11.6/LICENSE.txt)

Состав проверяется по положительному списку и побайтовой таблице нативного пакета.
Успешная проверка состава не означает приёмку генерации каждого публичного дома
или длительного мультиплеерного прохождения; эти границы указаны в ACCEPTANCE.md.
