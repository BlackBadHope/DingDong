# Original public artwork

Run `python generate.py --output <mod-source-directory>` with Python 3.12 or newer.
The generator uses only the standard library and the adjacent shape catalogue.
The catalogue records resource names, dimensions and the raw-image format version;
it contains no pixels, silhouettes, image embeddings, extracted palettes or fonts.

All 158 output images are original geometric artwork created for this public
edition. Equipment sheets preserve only the required engine frame dimensions.
Weapon families, sigils, armour pieces and panels are drawn from the primitives
in `generate.py`; no game or Workshop image is read. `ORIGINAL-ASSETS.json`
records each exact output hash and the generator hash.

The contact sheet is a source review preview, not an in-game visual acceptance.
Animation alignment still requires an in-game check on the public candidate.
These project-owned files do not change the rights to any third-party component.
