# DingDong Public 0.29.3 — кандидат

Это отдельная публичная версия собственного мода. Она не содержит игру,
движок, сторонние моды, Project tRU или сохранения. Для клиента нужны
официальный tModLoader и активная сессия Steam с правом доступа к Terraria.
Проверка Steam не предоставляет прав на распространение чужих файлов.

## Что заменено

- 90 файлов частных построек исключены. Вместо них 88 логических вариантов
  используют собственные детерминированные процедурные планы.
- Все 158 изображений заменены собственными геометрическими рисунками.
  Исходные пиксели не использовались. Это базовая графика; анимация брони
  и внешний вид в игре ещё не прошли приёмку.
- 36 схем Structify сохранены с их MIT notice.
- Внешние блоки перевода исключены. Project tRU устанавливается из официального
  источника; его содержимое не перепаковывается.
- Собственные прежние worldgen-guards перенесены в этот мод. Отдельный
  `PackWorldgenFix` в публичном наборе должен быть выключен.

## Кандидат исправления нагрузки сервера

Для расширенного мира число случайных обновлений роста и распространения
блоков ограничено бюджетом обычного Large-мира. Для стандартных миров операнды
сохранены. Координаты, жидкости, часы и спавн не изменяются этой правкой.
На карте площадью десять Large миров отдельный участок получает такие
обновления примерно в десять раз реже. Серверная настройка
`RandomTileBudgetConfig.AutoNormalizeExpandedWorldGrowth` позволяет вернуть
исходный бюджет. Подробности: [описание правки](DingDongBiomeHomes/Compatibility/RANDOM-TILE-BUDGET.md).

В живом сеансе измерены около 43 серверных обновлений в секунду при примерно
59 обновлениях клиента; основная доля профиля пришлась на случайные обновления
мира и Calamity tile growth. Это объясняет задержки симуляции, но не доказывает,
что правка устраняет каждую наблюдавшуюся телепортацию. FPS/мультиплеер с новым
кандидатом ещё не проверены.

## Сборка

Нужен .NET SDK 9 и установленный официальный tModLoader указанной версии.
Путь к его `tMLMod.targets` передаётся явно; игровые DLL в Git не входят.

```powershell
dotnet build DingDongBiomeHomes/DingDongBiomeHomes.csproj -c Release -p:TmlTargetsPath='<tModLoader>/tMLMod.targets' -p:BuildMod=false
```

Затем нативный `tModLoader.dll -server -build <исходники> -eac <собранная DLL>`
упаковывает мод в отдельную build-папку. Не запускайте эту команду с рабочим
профилем сохранений. Состав проверенного готового кандидата и хеши исходников
указаны в `manifests/public-candidate-0.29.3.json`.

## Границы проверки

Компиляция, упаковка и изолированные проверки планов домов/бюджета не заменяют
загрузку модов, проверку жилья, фонов, боя и мультиплеера в игре. Публичный установочный канал публикуется отдельно от личного FTP-канала.
Готовность установки и запуска до меню не является приёмкой новых миров,
всех процедурных домов или длительного мультиплеера. Точные результаты —
в корневом ACCEPTANCE.md.

На собственные файлы распространяется [разрешение репозитория](../LICENSE-ORIGINAL.txt).
Сторонний notice находится рядом с соответствующими ресурсами.
